# Writing

Dialogue, names, flavour text, and the voice the game speaks in.

**Belongs here**

- What a boss says, before a fight, during it, and after
- ACT and item descriptions, and the jokes inside them
- Names: bosses, attacks, items, and the game's own vocabulary
- Tone: how funny, how cruel, and how much the game explains itself

**Not here**

- How the text box behaves, which goes in [ui](../ui/ui.md)
- What the boss does while it is talking, which goes in [bosses](../bosses/bosses.md)

Write the line first and worry about the engine's text markup second. Read
[the rules](../rules/scope.md), and start from the [README](../README.md).
